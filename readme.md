# Порівняння ефективності алгоритмів пошуку підрядка

## Мета роботи

Метою роботи було порівняти ефективність трьох алгоритмів пошуку підрядка:

- Boyer–Moore;
- Knuth–Morris–Pratt (KMP);
- Rabin–Karp.

Дослідження проводилося на основі двох текстових файлів. Для кожного алгоритму вимірювався час пошуку підрядка, який існує в тексті, та підрядка, який відсутній. Для вимірювання часу виконання використовувалася функція `timeit`.

## Загальний висновок

За результатами проведеного тестування можна зробити такі висновки:

- Алгоритм **Boyer–Moore** показав найкращу швидкодію на обох текстах. Його висока продуктивність пояснюється використанням таблиці зсувів, що дозволяє пропускати частину символів тексту та зменшує кількість порівнянь.
- Алгоритм **Knuth–Morris–Pratt (KMP)** також продемонстрував стабільну продуктивність. Завдяки префіксній таблиці він не повертається до вже перевірених символів, що забезпечує лінійний час роботи навіть у несприятливих випадках.
- Алгоритм **Rabin–Karp** працює ефективно, однак додаткові витрати на обчислення та оновлення хешів, а також перевірку можливих колізій, можуть призводити до дещо більшого часу виконання порівняно з двома іншими алгоритмами.

Отримані результати свідчать, що для досліджуваних текстів найефективнішим виявився алгоритм **Boyer–Moore**, тоді як **Knuth–Morris–Pratt** забезпечує стабільну продуктивність незалежно від структури тексту. **Rabin–Karp** поступається іншим алгоритмам за швидкодією, проте залишається ефективним рішенням для задач пошуку підрядків, особливо коли необхідно виконувати пошук великої кількості шаблонів або використовувати хешування.
