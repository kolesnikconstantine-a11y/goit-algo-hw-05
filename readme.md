# Порівняння алгоритмів пошуку підрядка

## Мета роботи

Порівняти ефективність трьох алгоритмів пошуку підрядка:

- Boyer–Moore
- Knuth–Morris–Pratt (KMP)
- Rabin–Karp

Для двох текстових статей виконано пошук:

- існуючого підрядка;
- неіснуючого підрядка.

Час роботи вимірювався за допомогою бібліотеки `timeit`.

---

## Використані підрядки

### Стаття 1

Існуючий:

```
алгоритм
```

Неіснуючий

```
nonexistentpattern
```

---

### Стаття 2

Існуючий

```
рекомендаційної системи
```

Неіснуючий

```
nonexistent pattern for benchmarking
```

## Висновки

За результатами проведених експериментів можна зробити такі висновки.

Для першої статті найкращу швидкодію зазвичай демонструє алгоритм Boyer–Moore. Завдяки використанню таблиці зсувів він пропускає частину символів тексту, що зменшує кількість порівнянь.

Для другої статті результати також, як правило, показують перевагу Boyer–Moore або дуже близькі показники між Boyer–Moore та KMP.

Алгоритм Knuth–Morris–Pratt демонструє стабільний час роботи незалежно від структури тексту, оскільки не повертається назад під час пошуку.

Алгоритм Rabin–Karp працює ефективно, проте додаткові обчислення хеш-функції та перевірка можливих колізій часто роблять його трохи повільнішим за два інші алгоритми.

### Загальний висновок

У більшості випадків найшвидшим алгоритмом є **Boyer–Moore**, друге місце займає **Knuth–Morris–Pratt**, а **Rabin–Karp** демонструє дещо нижчу продуктивність.
